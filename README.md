# 🖥️ Server Health Checker

A lightweight and efficient server monitoring tool built with **Bash** to help administrators and developers keep track of essential system metrics. It provides a quick overview of server health by monitoring CPU utilization, memory consumption, disk usage, system uptime, and other critical resources, then generates an easy-to-read health report.

Designed with simplicity in mind, this tool requires no additional dependencies and can run on most Linux distributions out of the box. Whether you're managing a personal server, testing in a development environment, or performing routine system maintenance, **Server Health Checker** offers a fast and reliable way to identify potential resource bottlenecks before they become problems.

## ✨ Key Features

* Real-time CPU usage monitoring
* Memory (RAM) utilization analysis
* Disk space usage reporting
* System uptime tracking
* Overall server health summary
* Lightweight and dependency-free
* Easy to customize and extend
* Compatible with most Linux distributions

##.. 🎯 Why This Project?

Server Health Checker was created to simplify routine server monitoring by providing the most important system statistics in a single, easy-to-understand report. Instead of running multiple Linux commands individually, this script consolidates key performance metrics into one convenient utility, making it useful for both learning Linux system administration and performing quick health checks on production or development servers.
